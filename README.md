# 約時間小幫手🙋‍♀️

點日期、選時段，自動產生中英文的會議時段文字並複製到剪貼簿，直接貼進 LINE 或 Email。

**線上使用：** https://rubytsaitw.github.io/meeting-time-helper/

## 功能

- 日曆複選日期，一個日期可以掛多個時段
- 中／英文一鍵切換，括號與句點自動跟著換：`9/2（週三）` ↔ `9/2(Wed.)`
- 常用時段下拉選單，也可以自訂輸入
- 每個時段輸出一行，開頭語可選可自訂
- 產生後自動複製，並顯示提示

## 星期怎麼算的

星期不是預先寫死的文字，而是在使用者點選的當下由瀏覽器計算，並且用兩套互相獨立的演算法交叉比對：

1. JS `Date` 物件，以當地中午 `new Date(y, m-1, d, 12)` 建立，避開 UTC 字串解析與日光節約時間的邊界問題
2. Sakamoto 演算法，純整數運算，不依賴任何內建日期物件

兩者不一致就不輸出。頁面載入後會在背景把 1900–2100 共 73,414 天全部比對一遍，結果寫進瀏覽器 console。

## 技術

單一 HTML 檔，原生 JavaScript，沒有任何外部相依或建置流程。下載 `index.html` 用瀏覽器打開就能用。
